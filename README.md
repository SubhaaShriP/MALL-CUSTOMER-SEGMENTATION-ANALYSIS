# MALL-CUSTOMER-SEGMENTATION-ANALYSIS
**Mall Customer Segmentation Analysis** is a data analytics project that explores customer behavior using age, gender, annual income, and spending score data. Built with Python, Pandas, NumPy, Matplotlib, and Seaborn, it uses Exploratory Data Analysis (EDA) to uncover insights that support customer segmentation and business decision-making.
🎯 Objectives
- Analyze customer demographics and spending behavior.
- Study customer characteristics using Age, Gender, Annual Income, and Spending Score.
- Visualize customer patterns through Exploratory Data Analysis (EDA).
- Generate insights for better customer targeting and marketing strategies.
📊 Dataset
The dataset contains 202 customer records with the following attributes:
- Customer ID
- Gender
- Age
- Annual Income (k$)
- Spending Score (1–100)
🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
📈 Analysis Performed
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Age Distribution Analysis
- Gender-Based Analysis
- Income Distribution Analysis
- Spending Score Analysis
- Customer Behavior Visualization
🔍 Key Insights
- Female customers represent a larger share of customers.
- Most customers have annual incomes between 60K and 80K.
- Spending scores are concentrated between 40 and 60.
- Female customers show slightly higher average spending scores than male customers.
